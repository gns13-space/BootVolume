# BootVolume

[English](README.md) · [웹사이트](https://bootvolume.oodot.top)

**일정하게, 웅장하게 시작하는 Mac**

Mac의 음량은 자유롭게, 웅장한 부팅음은 일정하게. Mac의 기본 음량에 상관없이 항상 일정한 '부팅음만의 음량'을 설정해보세요.

macOS 15 이상 · Apple Silicon

## 터미널 없이 설정하는 부팅음 음량

### 로그인 후 음량 설정

Mac을 부팅하고 로그인하면 정해 둔 음량으로 설정됩니다. Mac 종료 전 음량으로 설정되게 할 수도 있습니다.

### 부팅음 음량 설정

Mac을 다시 켤 때 부팅음을 듣기 위해 종료 전 볼륨을 올려놓을 필요가 없습니다. 부팅음을 설정하면 종료 전 볼륨을 해당 값으로 설정합니다.

### 작동 상태 확인

앱이 알아서 작동 상태를 점검합니다. 부팅음 음량 설정 가능 유무, 업데이트 상태 등을 스스로 점검하고 상태를 사용자에게 표시합니다.

## 설치 방법

### 간단하게 설치

1. [GitHub에서 받기](https://github.com/gns13-space/BootVolume/releases/latest)를 눌러 BootVolume을 받습니다.
2. 압축을 풀고 BootVolume 앱을 응용 프로그램 폴더로 옮깁니다.
3. 앱을 실행합니다.

### 터미널로 빌드

터미널에 다음 명령어를 입력하여 빌드합니다. /Applications 폴더에 설치됩니다.

```sh
git clone https://github.com/gns13-space/BootVolume
cd BootVolume
./build.sh
```

서명은 `$BOOTVOLUME_SIGN_ID`, 키체인의 첫 번째 `Apple Development` 인증서, 임시 서명(ad-hoc) 순서로 찾아 씁니다.

### 설치한 뒤

1. 메뉴 막대의 스피커 아이콘을 누릅니다.
2. **도우미 설치**를 누르고 부팅음을 설정하여 설치 및 설정을 완료합니다.

## 앱이 정상적으로 작동하지 않는 경우

- **강제 종료**: 전원 버튼을 길게 눌러 강제 종료를 하면 앱이 작업을 하지 못해 다음 부팅음이 사전 설정된 음량으로 나지 않을 수 있습니다.
- **macOS 업데이트**: macOS가 새 버전으로 업데이트되면 부팅음이 사전 설정된 음량으로 나지 않을 수 있습니다. 해당 경우 도우미를 다시 설치해주세요.
- **Intel Mac 및 macOS 14 이하**: Mac이 Intel Mac이거나 macOS 버전이 14 이하인 경우 제대로 작동하지 않을 수 있습니다.

## 자주 묻는 질문

**부팅음이 나지 않아요**

패널 아래 '도우미'가 정상인지 확인해주세요. Mac을 강제 종료하여 끄면 도우미가 실행되지 못해 다음 부팅음이 나지 않을 수 있습니다. Mac '메뉴'의 '시스템 종료'를 통해 정상적인 방법으로 종료해주세요.

**관리자 암호는 왜 필요한가요?**

부팅음 음량이 기록되는 곳인 'NVRAM'을 덮어쓰려면 관리자 권한이 필요합니다. 도우미는 해당 값만을 수정할 수 있습니다. 또한 BootVolume은 오픈소스 프로그램으로서 안심하고 사용하실 수 있습니다. 걱정하지 말고 사용하세요!

**부팅음 음량 설정값을 변경하면 시스템 음량도 같이 변경되나요?**

BootVolume 패널에서 부팅음 음량 슬라이더를 움직이거나 부팅음 음량을 변경할 때 2~3초 정도 시스템 음량이 음소거 상태가 됩니다. 재생 중인 음악이나 영상이 있다면 잠시 음소거가 되어 소리가 들리지 않는 게 일반적인 동작이나, 때때로 예상치 못한 버그로 2~3초 동안 시스템 음량이 부팅음 음량 설정값대로 설정될 수도 있습니다. 해당 경우 재생 중인 음악이나 영상을 잠시 일시정지한 후 설정하는 것을 권장드립니다.

**어떤 Mac에서 되나요?**

macOS 15 이상, Apple Silicon Mac에서 사용 가능합니다. Intel Mac이나 macOS 14 이하의 경우 작동 유무를 확인할 수 없습니다. MacBook Air(M4) · macOS 27에서 시험했습니다.

**앱을 지우려면 어떻게 하나요?**

패널에서 '도우미 지우기'를 누른 뒤 앱을 종료하고 응용 프로그램 폴더에서 앱을 삭제하시면 됩니다. 남은 설정과 기록까지 지우려면 터미널에 다음 명령어를 입력합니다.

```sh
defaults delete top.oodot.bootvolume
rm -f ~/Library/Logs/BootVolume.log
sudo rm -f /var/log/bootchime.log
```

## 동작 방식

Apple Silicon Mac의 부팅음은 NVRAM 값 `SystemAudioVolumeExtension`을 읽습니다. 이 값은 2바이트이고, 둘째 바이트의 맨 앞 비트가 음소거를 뜻합니다. 음량을 바꾸면 macOS가 이 값을 고쳐 씁니다. 하지만 종료하는 도중에 바꾼 음량은 제때 기록되지 않습니다. 그래서 BootVolume은 이렇게 작동합니다.

1. **음량 측정**: 부팅음 음량을 설정하면 앱이 음소거를 켠 채로 시스템 음량을 잠깐 그 값으로 맞추고, macOS가 기록한 2바이트를 읽은 뒤 원래 음량과 음소거 상태로 되돌립니다. 음소거 중에도 macOS는 음량 값을 기록하기 때문에 측정하는 동안 소리가 커지지 않습니다. 이 값의 형식은 공개되어 있지 않아 항상 사용자의 Mac에서 직접 측정합니다.
2. **종료할 때 쓰기**: 관리자 권한으로 작동하는 도우미(`top.oodot.bootchime`)가 Mac이 종료되기를 기다립니다. 종료 신호를 받으면 측정한 값을 `SystemAudioVolumeExtension`에 씁니다. 0.5초 뒤 한 번 확인하고, 값이 바뀐 경우에만 다시 씁니다.
3. **로그인 후 맞추기**: 앱이 실행되자마자 음량을 맞추고, 1·3·6초 뒤에 한 번씩 더 맞춥니다.

**부팅음 켜기** 스위치는 부팅음을 막는 두 값(`StartupMute=%01`, 옛 방식의 `SystemAudioVolume=%80`)도 지웁니다.

### 파일

| 경로 | 소유 | 용도 |
|---|---|---|
| `/Library/Application Support/BootVolume/bootchime.sh` | root | 도우미 스크립트 |
| `/Library/Application Support/BootVolume/chime-value` | 사용자 | 측정한 값(16진수 4자) |
| `/Library/LaunchDaemons/top.oodot.bootchime.plist` | root | 도우미 데몬 |
| `/var/log/bootchime.log` | root | 도우미 기록 |
| `~/Library/Logs/BootVolume.log` | 사용자 | 앱 기록 |

두 기록과 상태 점검은 **설정 → 기록** 탭에서 확인하실 수 있습니다.

### 보안

도우미가 관리자 권한으로 작동하기 때문에 다음과 같이 보호합니다.

- 도우미는 `chime-value`를 읽기만 합니다. 16바이트를 넘는 파일은 읽지 않고, 소문자 16진수 4자일 때만 씁니다. 그 밖의 경우에는 아무것도 쓰지 않고 오류를 기록합니다.
- 도우미를 설치할 때 앱 폴더가 실행 중인 앱의 서명 조건을 만족하는지 먼저 확인합니다. 그다음 관리자만 쓰는 임시 폴더로 복사하고, 서명을 다시 확인한 뒤 원본과 같은지 비교합니다.
- 관리자 스크립트는 파일로 저장하지 않고 `osascript`에 인자로 바로 넘깁니다.
- 앱 설정에서 읽은 값은 관리자 스크립트에 넣기 전에 검사합니다.

### 디버그 옵션

```sh
open -n /Applications/BootVolume.app --args --test-poweroff   # 종료 알림 테스트
open -n /Applications/BootVolume.app --args --test-measure    # 부팅음 음량 다시 측정(설정이 바뀜)
```

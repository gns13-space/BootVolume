작동 상태 확인

앱이 알아서 작동 상태를 점검합니다. 부팅음 음량 설정 가능 유무, 업데이트 상태 등을 스스로 점검하고 상태를 사용자에게 표시합니다.

설치 방법

간단하게 설치

  1. 아래 'GitHub에서 받기'를 눌러 BootVolume을 설치합니다.
  2. 압축을 풀고 BootVolume 앱을 응용 프로그램 폴더로 옮깁니다.
  3. 앱을 실행합니다.
GitHub에서 받기

터미널로 빌드

터미널에 다음 명령어를 입력하여 빌드합니다. /Applications 폴더에 설치됩니다.

$ git clone https://github.com/gns13-space/BootVolume
$ cd BootVolume
$ ./build.sh

설치한 뒤

  1. 메뉴 막대의 스피커 아이콘을 누릅니다.
  2. 도우미 설치를 누르고 부팅음을 설정하여 설치 및 설정을 완료합니다.

앱이 정상적으로 작동하지 않는 경우

  • 강제 종료전원 버튼을 길게 눌러 강제종료를 하면 앱이 작업을 하지 못해 다음 부팅음이 사전 설정된 음량으로 나지 않을 수 있습니다.
  • macOS 업데이트macOS가 새 버전으로 업데이트되면 부팅음이 사전 설정된 음량으로 나지 않을 수 있습니다. 해당 경우 도우미를 다시 설치해주세요.
  • Intel Mac 및 macOS 14 이하Mac이 Intel Mac이거나 macOS 버전이 14 이하인 경우 제대로 작동하지 않을 수 있습니다.

자주 묻는 질문

패널 아래 '도우미'가 정상인지 확인해주세요. Mac을 강제종료하여 끄면 도우미가 실행되지 못해 다음 부팅음이 나지 않을 수 있습니다. Mac '메뉴'의 '시스템 종료'를 통해 정상적인 방법으로 종료해주세요.

부팅음 음량이 기록되는 곳인 'NVRAM'을 덮어쓰려면 관리자 권한이 필요합니다. 도우미는 해당 값만을 수정할 수 있습니다. 또한 BootVolume은 오픈소스 프로그램으로서 안심하고 사용하실 수 있습니다. 걱정하지 말고 사용하세요!

BootVolume 패널에서 부팅음 음량 슬라이더를 움직이거나 부팅음 음량을 변경할 때 2~3초정도 시스템 음량이 음소거 상태가 됩니다. 재생 중인 음량이나 영상이 있다면 잠시 음소거가 되어 소리가 들리지 않는게 일반적인 동작이나, 때때로 예상치 못한 버그로 2~3초동안 시스템 음량이 부팅음 음량 설정값대로 설정될 수도 있습니다. 해당 경우 재생 중인 음악이나 영상이 있다면 잠시 일시정지 후 설정하는 것을 권장드립니다.

macOS 15 이상, Apple Silicon Mac에서 사용 가능합니다. Intel Mac이나 macOS 14 이하의 경우 작동 유무를 확인할 수 없습니다.

패널에서 '도우미 지우기'를 누른 뒤 앱을 종료하고 응용 프로그램 폴더에서 앱을 삭제하시면 됩니다.
